The vulnerability report was submitted through **Patchstack**, validated, assigned **CVE-2026-115431**, and is now published to global vulnerability databases (Patchstack & Wordfence Intelligence).

# Broken Access Control in Motors – Car Dealership & Classified Listings Plugin (CVE-2026-123468)

## Summary

A Broken Access Control (Missing Authorization / OWASP A1) vulnerability was identified in the **Motors – Car Dealership & Classified Listings Plugin** WordPress plugin by StylemixThemes (affected versions **<= 1.4.128**, patched in **1.4.129**).

The vulnerability report was submitted to **Patchstack**, validated, assigned **CVE-2026-123468** (PSID: `fd60a8f0fc16`), and is now published to the public Patchstack vulnerability database.
