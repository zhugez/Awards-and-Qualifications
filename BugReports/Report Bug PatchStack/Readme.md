# Broken Access Control in Upsell Order Bump Offer for WooCommerce

## Summary

A Broken Access Control vulnerability was identified in the **Upsell Order Bump Offer for WooCommerce** WordPress plugin.

The vulnerability report was submitted to **Patchstack** and has been **validated**. Patchstack confirmed that the report is being processed and that the vendor will be contacted where applicable so the issue can be addressed.
